# Manual de usuario — borrador

La aplicación todavía no existe. Estos recorridos describen intención de SRC-01/SRC-02; nombres de controles y capturas se confirmarán contra UI implementada.

- **Cliente:** iniciar sesión → explorar/buscar → ver producto y comercio → carrito de ese comercio → elegir QR simulado o efectivo → confirmar → consultar pedido, ubicación, plazo y código → retirarlo presencialmente.
- **Comercio:** iniciar sesión con rol autorizado → gestionar catálogo/stock → confirmar y preparar pedido → marcar listo → validar credencial del cliente y, si corresponde, confirmar efectivo → entregar.
- **Administrador:** gestionar comercios/categorías/usuarios y supervisar pedidos; pantallas y permisos exactos pendientes DEC-10/13.

Capturas necesarias al implementar: UI-01–10, incluida UI de error, agotado, pedido expirado y código inválido. Base visual: [[02-Arquitectura/Mapa de pantallas]]. No presentar este borrador como manual probado.
