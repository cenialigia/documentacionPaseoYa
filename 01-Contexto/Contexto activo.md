# Contexto activo y ruta de lectura

**Proyecto:** PaseoYA; **Core vivo:** `PaseoYA-Core`; **estado:** planificación documental ampliada con mockup Stitch (2026-10-02), sin implementación. **Cerebro de dominio:** no asociado en el catálogo; `nextjs+nestjs/Plantilla-Core-Proyecto` se usó exclusivamente como modelo de estructura solicitado por Paulo. La tecnología y las reglas de este proyecto viven aquí, no se heredan de Next/Nest.

**Núcleo para cualquier agente:** [[00-Inicio]] → [[01-Contexto/Definicion del proyecto]] → [[02-Arquitectura/Decisiones pendientes]] → requisito y prueba de su módulo. Para pedir respuestas a Paulo, usar [[Decisiones de Usuario para el desarrollo]]. Para UI, añadir [[02-Arquitectura/Especificacion UI LUI-01]] (tokens, rutas, componentes, estados y fixtures propuestos), [[02-Arquitectura/Mapa de pantallas]], [[02-Arquitectura/Mockup Stitch - vistas y ubicaciones]] y [[05-Desarrollo/Plan por fases]]; los [[02-Arquitectura/Wireframes iniciales]] son V0 previos. Para datos/stock, añadir [[04-Reglas-de-negocio/_Indice de reglas]] y [[02-Arquitectura/Vision general]]. Para demo, añadir [[08-Produccion/_Indice de produccion]].

**Entradas fuente:** SRC-01 PDF oficial del reto, SRC-02 Markdown de requisitos v1, SRC-04 ZIP Stitch; originales conservados en [[09-Entradas/_Indice de entradas]]. Se consultan bajo demanda si hay duda o contradicción. El PDF contiene siete páginas del Reto 3; no hay imágenes de UI de PaseoYA en sus páginas. Los bocetos y mockups son propuestas visuales, no permisos ni implementación.

**Límites actuales:** planificar/documentar, no código ni cuentas. No inventar reglas para cobros reales, expiración, privacidad o autorización. Si cambia una fuente, revisar sus decisiones, RF/RN, tareas y pruebas dependientes; no releer todo el baúl.

**Ruta de handoff:** anotar objetivo, IDs afectados, cambios reales, prueba con resultado, decisión pendiente, próxima acción y fuentes leídas en [[06-Estado/Bitacora]]. Consumo de tokens sólo si el runtime lo informa; desconocido = `null`.
