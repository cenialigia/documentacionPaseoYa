# Glosario

| Término | Significado operativo | No confundir con |
| --- | --- | --- |
| Comercio | Establecimiento del Paseo con catálogo, stock y pedidos propios | Administrador del marketplace |
| Carrito | Intención temporal de compra para un único comercio | Pedido confirmado |
| Pedido | Registro creado en checkout para un comercio | Carrito editable |
| Reserva | Stock comprometido por pedido, especialmente efectivo pendiente | Stock disponible |
| Pago QR simulado | Resultado de demostración sin transacción bancaria | Código/QR de retiro |
| Código de retiro | Credencial presentada físicamente y validada por comercio | Comprobante de pago |
| Estado de pedido | Preparación/entrega/cancelación/expiración | Estado de pago |
| RLS | Políticas de acceso a filas de PostgreSQL/Supabase | Validación visual en la app |
| Evidencia | Resultado de prueba o demo con fecha y alcance | Requisito redactado |
